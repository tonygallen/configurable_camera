( appsrc name=source is-live=true block=false format=time caps=video/x-raw,format=RGB,width=%d,height=%d,framerate=%d/1 !
 tee name=t ! queue name=raw_queue ! splitmuxsink name=sink muxer=identity location=/dev/null max-size-time=600000000000 t. !
 queue name=rtsp_queue ! nvvidconv name=converter ! video/x-raw(memory:NVMM),format=I420,framerate=%d/1 !
 nvv4l2h264enc bitrate=20000000 profile=4 preset-level=2 maxperf-enable=true ! h264parse ! video/x-h264,alignment=au,stream-format=byte-stream ! rtph264pay name=pay0 )

______________

This file configures the GStreamer pipeline for event camera sources (e.g. DVXplorer, EVK4).
The appsrc element is fed raw RGB frames by the faery frame feeder subprocess.

The pipeline description spans four lines of text, following the same structure as pipeline.txt:
 - To create the combined rtsp/raw pipeline, the app reads and concatenates all four lines.
 - To create the rtsp-only pipeline, the app skips the second line (tee and raw recording branch).
 - All content related to the raw branch and tee structure is contained to the second line.
 - Each line except the fourth ends with "!" and each line except the first starts with " "
   to link it to the next element on the next line.
 - The %d format placeholders are filled in with the event camera width, height, and frame rate.
   The four values (in order) are: width, height, framerate (appsrc caps), framerate (converter caps).

The function gst_pipeline_txt_gen, implemented in src/config.c, is responsible for reading this file.
